Eine Web-App, um das Quizspiel „Der Dümmste fliegt“ mit Freunden zu leiten. Der Spielleiter steuert das Spiel am Laptop: Timer, aktuelle Frage mit Antwort, Leben pro Spieler und eine Reihenfolge, die reihum geht. Ein eigener Game Screen für Fernseher oder Bildschirmfreigabe zeigt Spieler, Leben und Ergebnisse und hält Antworten bis zum Rundenende verborgen.

Die Spieler stimmen am eigenen Handy ab: Der Spielleiter öffnet einen Raum, die Spieler treten mit einem vierstelligen Code oder einem Link bei, und alle wählen geheim die dümmste Antwort. Bei Gleichstand gibt es eine Stichwahl. Jeder Spieler bekommt eine Figur, die aus mehreren Stilen gebaut oder selbst gezeichnet werden kann. Der Server ist ein kleines Node-Programm ohne Pakete und bringt 499 Startfragen mit.
