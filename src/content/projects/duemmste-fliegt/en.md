A web app for hosting the quiz game “Der Dümmste fliegt” with friends. The host runs the game on a laptop: timer, the current question with its answer, lives per player and an order that goes around the table. A separate game screen for a TV or screen share shows players, lives and results, and keeps answers hidden until the round is over.

Players can vote from their own phones: the host opens a room, players join with a four-digit code or a link, and everyone votes secretly for the weakest answer. Ties lead to a runoff. Each player gets an avatar that can be built from a set of styles or drawn by hand. The server is a small Node program without any packages, and it comes with 499 starting questions.
